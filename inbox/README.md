# Photo inbox

Upload photos for the website here. The agent picks them up on its next
weekday run, resizes them, places them on the right page and then
removes them from this folder.

## How to upload
1. Open this folder on GitHub.
2. Press "Add file", then "Upload files".
3. Drag the photos in and press "Commit changes".

## How to name the files
Name each file so it is clear where it belongs: the artist first, then
what it shows.

- `zara-muse-portrait.jpg` for a photo of the artist
- `zara-muse-in-her-own-light.jpg` for an artwork, using its title
- `konn-artiss-anti-frieze-install-1.jpg` for an installation view

Use JPG for photos. Send the largest version you have. If the agent
cannot tell where a photo belongs it leaves it here and asks you in its
report.

Anything in this folder can be seen by the public, because the
repository is public. Only upload photos you are happy to publish.
