# Photo inbox

Photos waiting for the agent to place them on the site.

The easy way to add photos is Artiscope Digital Home: open Photos,
add your pictures and choose the exact spot for each one.

You can also upload here by hand. Name each file by artist and what it
shows, for example `zara-muse-portrait.jpg`, and the agent will work
out where it belongs or ask you.

Files named `slot--...` were sent from the console and already know
their spot. Please leave those names as they are.

Anything in this folder can be seen on GitHub by the public until the
agent places it. Only upload photos you are happy to publish.
